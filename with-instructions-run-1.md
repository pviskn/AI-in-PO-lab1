## Итоговое сообщение агента (кратко)

- Мягкое удаление через `DeletedAt`, строка в БД остаётся (есть интеграционный тест на это).
- Удалённые авто скрыты из `GET /api/cars`; по id, при смене статуса и при создании заявки возвращается 404.
- `DELETE /api/cars/{id}` → 204, `POST /api/cars/{id}/restore` → 200 с авто. 404 / 401 / 403 для соответствующих случаев. Оба эндпоинта добавлены в таблицу README.
- Повторное удаление или восстановление неудалённого авто → 409 Conflict, у каждого случая свой тип ошибки, обработанный в `ExceptionHandlingMiddleware`.
- Решения на проверку: удалённое авто нельзя арендовать; VIN остаётся занятым; в старых заявках удалённое авто по-прежнему отображается (фильтр только в запросах авто, без глобального query filter); миграция не нужна.
